# Calculator API

A simple REST API built with FastAPI.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Technologies

- Python
- FastAPI
- Uvicorn
- Pydantic

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python -m uvicorn app.main:app --reload
```
